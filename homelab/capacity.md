기준 사례 — 2024년 한국시리즈 극장 생중계 예매, 대기 16만 명.
사용자 단계(첫 화면 → 대기열 진입 → 순번 조회 → 입장 → 예매)마다 SLO를 테스트 전 확정, 같은 여정을 k6로 재현.
테스트마다 **먼저 막힌 곳**을 찾아 구조를 바꾸며 dev 1만 → stg 5만 명까지 통과.
{:.lead}

## SLO — 테스트 전 확정

| 단계 | 성공 기준 · 목표 | 이유 |
|---|---|---|
| 1 첫 화면 | 응답 2xx · **99.9%** | 실패하면 뒤 단계에 사용자가 오지 않아 다른 SLO가 통과처럼 보임 |
| 2 대기열 진입 | 진입 요청 성공 · **99.9%** | 대기열의 역할이 전원 수용이라 가장 엄격 |
| 3 순번 조회 | 1초 이내 성공 · **99%** | 가장 짧은 갱신 주기가 1초 — 넘으면 대기 화면이 밀림 |
| 4 입장 반영 | 입장 후 1초 이내 booking에 반영 · **99.9%** | 반영 전 좌석을 누르면 거부(403) — 요청 지표에는 실패로 안 잡힘 |
| 5 예매 여정 | 회차 → 좌석 → 선점 → 확정 각 1초 이내 성공 · **99%** | 확정만 세면 앞 단계 실패가 가려짐 · 매진 응답(409)은 제외 |
{:.hl-res}

- **목표값** — 지연 기준 1초는 사람이 지연을 느끼는 선, 99.9%는 업계 표준선에서 시작한 초기값
- **불변식** — 정원 초과 0 · 처리 안 된 입장 메시지 0 · 5xx 0 · 입장 후 거부(403) 0, 하나라도 어기면 무효
- **판정** — k6가 아닌 서버 지표(Mimir) 기준 · 예매 오픈 1분 전부터 5분 뒤까지 · 매번 좌석 4,000 · 대기 0에서 시작

## 병목이 옮겨 간 순서

| 규모 · 증상 | 원인 | 조치 → 결과 |
|---|---|---|
| **dev 3만 명** — k3s 재시작 | Redis는 CPU 44%로 여유 · Traefik 동시 연결 1만 명 458 → 3만 명 **22,866**으로 노드 메모리 고갈 | 노드 RAM 8GB × 3 한계 — 부하 측정을 stg(EKS)로 이전 |
| **stg 1만 명** — 예매 오픈 순간 입장 반영 최대 **4.59초** | 새로 뜬 booking의 JVM 컴파일이 CPU 117초 점유 — 같은 노드 Kafka 브로커는 CPU 경합 시 배분 7% | **booking 전용 노드그룹** · 브로커 CPU 보장 → **0.251초** |
| **stg 2.5만 명** — 대기열 진입 1초 이내 **60.912%** | 노드 4 → 3 축소로 queue 파드 2대가 한 노드 — CPU 차례 대기, Redis는 여유 | 노드 4대에 파드 1대씩 분산 강제 → **100.000%** |
| **stg 3만 명** — k6 `connection reset` 다발 | 부하 발생기 EC2 1대의 초당 패킷 한도 — 초과 패킷을 오류 없이 폐기, 서버는 여유 | 발생기 4대 × 12,500명으로 분산 |
| **stg 5만 명** — SLO 통과, 대기열 진입 1–2.5초 **13,641건** | queue 파드 4대 중 2대에 연결 **27배** 집중 → Redis 연결 풀 대기 | **미해결** — 느린 파드에 ALB 연결이 더 몰리는 구조로 추정 |
{:.hl-tbl}

## 10만 명으로 가려면

- **병목 축은 파드당 동시 요청 수** — 사전 계산은 두 번 모두 Redis를 지목했지만 실측은 두 번 모두 동시 연결이 먼저 한계 → 조정 대상은 파드 수 · 파드당 동시 요청 상한
- **계산** — 정원 1,000 · 초당 100명 입장이면 10만 명 전원 입장 약 16분, 좌석 4,000은 약 80초에 소진 — 약 9만 6천 명은 성능이 아닌 제품 정책의 영역

## 한계

- **실측 상한 5만 명** — 10만은 발생기 vCPU(계정 한도 64)에 막혀 미측정, 이후는 계산
- **대기열 진입을 1초 이내 기준으로 보면 5만 명 73.096%** — SLO는 성공률 기준으로 통과
- **장시간(soak) 테스트 없음** — 모두 12–15분 실행, 메모리 · 커넥션 누수 미확인

## 기술 스택

k6 · Terraform(부하 발생기) · Grafana · Mimir · Loki · Tempo
